INSTALL                                                           *ci-install*

With |vim.pack| (Neovim 0.12+): >lua
    vim.pack.add({
      'https://forge.barrettruth.com/barrettruth/ci.nvim',
    })
< Or via luarocks: >
    luarocks install ci.nvim
<
==============================================================================
CONFIGURATION                                                      *ci-config*

Configure ci.nvim by setting |vim.g.ci| before the plugin loads: >lua
    vim.g.ci = {
      debug = false,
    }
<
                                                                    *vim.g.ci*
Fields:

    debug ~
        boolean|string, default `false`

        Enable debug logging. When a string, log to that file path instead of
        emitting |vim.notify()| messages.
